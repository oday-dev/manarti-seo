# منارتي - نظام المحاسبة المتكامل
## Manarti Accounting System

نظام محاسبة متكامل مبني بتقنية Node.js/Express مع واجهة مستخدم بالعربية وفق نظام القيد المزدوج.

---

## المميزات الرئيسية

- **شجرة الحسابات** - دليل حسابات متكامل (أصول، خصوم، حقوق ملكية، إيرادات، مصروفات)
- **إدارة العملاء والموردين** - مع كشوف الحسابات
- **القيود اليومية** - نظام القيد المزدوج مع التحقق التلقائي من التوازن
- **التقارير المالية**:
  - ميزان المراجعة
  - الميزانية العمومية
  - قائمة الدخل
  - دفتر الأستاذ العام
  - كشف حساب
- **واجهة عربية RTL** مع دعم الطباعة
- **لوحة تحكم** تلخيصية

---

## التشغيل

```bash
cd backend
npm install
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

---

## التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| Backend | Node.js + Express |
| قاعدة البيانات | JSON file-based storage |
| Frontend | HTML5 + Bootstrap 5 RTL |
| اللغة | العربية (RTL) |

---
